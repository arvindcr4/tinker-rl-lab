## Agent skills

### Issue tracker

Issues and PRDs live as GitHub issues on `pes-llm-research/tinker-rl-lab` (via the `gh` CLI). See `platform_hybrid/docs/agents/issue-tracker.md`.

### Triage labels

Default canonical vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `platform_hybrid/docs/agents/triage-labels.md`.

### Domain docs

Multi-context: `CONTEXT-MAP.md` at the root points to per-context `CONTEXT.md` files. See `platform_hybrid/docs/agents/domain.md`.
