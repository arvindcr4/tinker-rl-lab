# docs/agents/ — INDEX

**Purpose:** Config that tells engineering skills/agents how to work in this repo (domain-doc layout, issue tracker, triage vocabulary).

**Key files:**
- `domain.md` — this is a multi-context repo; read `CONTEXT-MAP.md` + relevant `CONTEXT.md` + `docs/adr/` before exploring. Proceed silently if absent.
- `issue-tracker.md` — issues/PRDs live as GitHub issues on `pes-llm-research/tinker-rl-lab`; `gh` CLI recipes.
- `triage-labels.md` — maps canonical triage roles (needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix) to this repo's label strings.

**Find it fast:**
- to file/query issues → `issue-tracker.md`
- to pick a triage label → `triage-labels.md`
