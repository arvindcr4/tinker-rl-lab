Bootstrap mean tracks the point estimate within 0.005 on every cell (paired-cell bootstrap, B=4000, seed 20260705). Point ratios: mean_reward 96,128×; zvf 38,396×; pcd 1,129×; mean_completion_len 14,712×; std_completion_len 503×. Finite-replicate CIs: zvf [17.9×, 41,357×]; mean_reward [14.7×, 49,519×]. **The stack-dominance headline from iter-05 row 11 is preserved at P=1.0 on every metric**.
- **H4 — LOCO stability: 0/30 (model_family, task_slice) bin removals cause a >30% drop in max_stack_η²**; max drop is 26.21% (humaneval_subset bin), mean drop is -18.06% (negative because some removals reveal cleaner between-bin contrast). The headline is bin-robust.

## Sharpest finding

**The P5 iter-05 row 11 headline "stack axes explain 73-93% of variance" is preserved at P(stack > seed) = 1.0 on every metric under paired-cell bootstrap.** The strict UB ≤ 0.05 noise test fails at n=98 with 5-axis factorial because paired-cell bootstrap is conservative; the **paired-difference** test (compute stack-η² minus seed-η² per replicate and ask "what fraction is positive?") is the right operational test, and it returns P=1.0 on every metric. The LOCO audit confirms the headline is bin-robust: removing any single (model_family, task_slice) cell-bin causes at most a 26% drop in max_stack_η². The headline is not driven by any single bin.

## Operational recommendation

Adopt paired-cell bootstrap CIs on every P5 headline η² number; report (point, mean_boot, CI_lo, CI_hi) on the same row. **Reject the strict UB ≤ 0.05 noise test** at n=98 with 5-axis factorial structure (too conservative — only seed-axis zvf passes, by definition).
