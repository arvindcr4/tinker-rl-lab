## CI recommendations

A new `review09-offline.yml` adds:

- A lightweight pytest lane without torch, under a network namespace with no network access
- Required scientific groups with Hypothesis explicitly imported, network denied and live credential variables removed; JUnit inspection fails on absent/skipped/failed required groups
- A wheel installed into an independent environment, then imports and CLI help exercised outside the checkout with network denied
- Shell syntax checking and fake-executable behavioral tests

The existing workflow already includes a checksum-pinned native Tectonic/document-build lane. This patch adds a real figure-rendering test with distinctive synthetic measurements, inspecting rendered annotation values and nonempty PDF/PNG signatures. It does not run CI, install missing local packages, or rebuild published documents locally.

Follow-up: Hypothesis 6.170.1 was installed in the review environment. Both property modules now run locally. They exposed a precision regression in the new immutable advantage snapshot: Python floats were rounded to float32 before conversion to float64 log probabilities. Snapshotting now preserves input precision and detachment, with deterministic counterexample fixtures. Both property modules plus objective regressions pass (112 tests).

## Protocol migration

1. Thesis claim bindings: put `claim_bindings.json` beside the selected thesis chapters, with schema `thesis-claim-bindings-v2` and `claims` mapping each exact registry group to an ordered list of `{ "span": "unique-id", "label": "GRPO accuracy" }`. Mark the actual manuscript value as `<!-- claim: unique-id -->GRPO accuracy: 0.90<!-- /claim: unique-id -->`. IDs must occur exactly once, and a span contains one value. Do not mechanically annotate a matching number elsewhere in the chapter. Regenerate a v2 audit only after reviewing these semantic assignments.
2. Statistics: pass `--contract contract.json`; schema `stats-measurement-v2` requires `metric`, `unit`, `split`, `endpoint_step`, `expected_seeds`, `protocol_id`. Supported unit contracts are accuracy/fraction, reward/mean/reward, eval/percent_correct/percent. Every metric row carries `step`, `unit`, `split`, `protocol_id` and the selected metric. Historical logs require explicit `--legacy-exploratory`.
3. Objective default becomes `grpo-on-policy-v3`; previous explicit protocol IDs do not silently resume as v3.
4. `seed-runtime-v2` uses `python_hash_seed: null` rather than claiming runtime activation. Set the environment in the parent process before Python starts.
