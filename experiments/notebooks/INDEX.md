# experiments/notebooks/ — INDEX

**Purpose:** Six tutorial Jupyter notebooks, one per core Tinker recipe — config explanations, training commands, metric interpretation, result analysis. Entry point for learning the recipes.

**Key files:**
- `01_math_rl_arithmetic.ipynb` — RL to add two-digit numbers (GRPO, verifiable reward; 69.5%→100%).
- `02_chat_sl_sft.ipynb` — supervised fine-tuning on the NoRobots dataset.
- `03_preference_shorter.ipynb` — pairwise preference learning for shorter responses.
- `04_distillation_off_policy.ipynb` — off-policy distillation (SFT on OpenThoughts3).
- `05_distillation_on_policy.ipynb` — on-policy distillation via teacher-KL minimization.
- `06_math_rl_gsm8k.ipynb` — RL on GSM8K word problems (chain-of-thought).

**Find it fast:**
- simplest end-to-end RL example → `01_math_rl_arithmetic.ipynb`
- word-problem / CoT RL → `06_math_rl_gsm8k.ipynb`
