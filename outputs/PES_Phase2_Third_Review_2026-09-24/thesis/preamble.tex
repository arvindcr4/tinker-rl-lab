% ---- LONG UNBREAKABLE STRINGS: allow line breaks inside \texttt ----
%=====================================================================
% The corpus contains file paths, JSON fragments, model ids, W&B keys and
% SHA-256 digests far wider than the text column and containing no spaces.
% Measured on the 2026-09-25 build with pdftotext -bbox: 72 of 217 pages
% (33%) carried ink past the right text margin at 523.3pt, worst case
% 602pt on a 595pt-wide A4 page -- i.e. text physically off the paper.
% Every offending token was an unbreakable \texttt path/hash/URI.
%
% Fix, verified in isolation (max ink 523.3pt vs 523.3pt limit, 0 overflow):
%   * xurl     -- breaks \url{} and path-like strings at their delimiters
%   * seqsplit -- breaks arbitrary long unbroken tokens (hashes, URIs) at
%                 any character, via the \longtok wrapper
% The \longtok/sub-token rewriting is applied automatically by a source-level
% pass in build_thesis.py; short identifiers are left alone so ordinary words
% such as tinker-new-research are NOT hyphenated mid-word (the [htt]hyphenat
% option was tried and removed for exactly that reason).
\usepackage{xurl}
\usepackage{seqsplit}
\newcommand{\longtok}[1]{\texttt{\seqsplit{#1}}}
