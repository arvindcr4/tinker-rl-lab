Here is the complete implementation for the Bloomberg Terminal-style dashboard.

### Prerequisites
You must have a Supabase project.
1. Create a project at [supabase.com](https://supabase.com).
2. Run the SQL provided in `supabase_schema.sql` in your Supabase SQL Editor.
3. Get your `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
4. Create a `.env.local` file in the root directory with these keys and an OpenAI API key.
