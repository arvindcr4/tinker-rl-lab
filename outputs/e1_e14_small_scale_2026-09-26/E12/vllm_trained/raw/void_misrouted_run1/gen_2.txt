Here is the complete implementation for the Hospital Patient Tracking Board.

### Technical Architecture
*   **Framework**: Next.js 14+ (App Router).
*   **Styling**: Tailwind CSS for responsive, hospital-grade UI.
*   **Database/Auth**: Supabase (PostgreSQL, Auth, Realtime).
*   **State Management**: React Context + Supabase JS Client subscriptions for real-time sync.
*   **Icons**: Lucide React.
