## Two blockers cleared that were not credential problems

**1. The README command does not parse under harbor 0.20.0.** `--task-name` was
removed; it is now `--include-task-name` / `-i`. README lines 36-42 and 48-56
are stale.

**2. The task Dockerfiles are broken on arm64 hosts.** Stage 2 of every task
environment is `FROM binaryaudit-base:latest` with no `--platform`. BuildKit
resolves it for the host platform, and the amd64-only base image has no arm64
entry:

```
#3 [internal] load metadata for docker.io/library/binaryaudit-base:latest
#3 ERROR: no match for platform in manifest: not found
```

Fix without patching upstream: export `DOCKER_DEFAULT_PLATFORM=linux/amd64`.
This is not the `binfmt` issue the README's Troubleshooting section describes —
that one is about cross-compilation inside the build; this one is manifest
resolution and hits *every* task on arm64. Evidence:
`jobs/e7_boundary_probe/dnsmasq-backdoor-detect__WLLu2Es/exception.txt`.
