Task: codeocean_hard

Your goal is to test the computational reproducibility of the repository cloned to your current directory, which is code from a scientific paper. Specifically, you need to Create a 'figures' directory in the results folder. Run 'ktc_11_paper.Rmd' using Rscript and render it as html. Save the output to the ../results output directory. Set clean to 'TRUE'.. Save your report to a file named report.json in the environment directory you started in that contains the capsule itself, where you fill in all of the following fields: dict_keys(['fig Report the name of the material with the highest Depth Below Surface at 10,000 calibrated years BP.', 'fig Report the name of the material with the highest mass (g) and 5000 years cal. BP.']). You should install all of the requirements found in the Readme file and then run the commands necessary to answer the questions.
