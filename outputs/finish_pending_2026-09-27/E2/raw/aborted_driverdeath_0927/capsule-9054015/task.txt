Task: codeocean_hard

Your goal is to test the computational reproducibility of the repository cloned to your current directory, which is code from a scientific paper. Specifically, you need to Run 'pancancer_calculation.R' using Rscript.. Save your report to a file named report.json in the environment directory you started in that contains the capsule itself, where you fill in all of the following fields: dict_keys(['fig Report the percentage sensitivity for cancers A and B that has the highest number of cancers detected per 1,000 women for a 1.0% prevalance of cancer B.', 'Report the 5-year probability of diagnosis for breast tissue origin and age 50.']). You should install all of the requirements found in the Readme file and then run the commands necessary to answer the questions.
