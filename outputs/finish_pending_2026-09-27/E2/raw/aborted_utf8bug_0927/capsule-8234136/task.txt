Task: codeocean_hard

Your goal is to test the computational reproducibility of the repository cloned to your current directory, which is code from a scientific paper. Specifically, you need to Run 'main.py' with GOBI as the scheduler argument. Run 'main.py' with A3C as the scheduler argument. Then, run 'grapher.py'.. Save your report to a file named report.json in the environment directory you started in that contains the capsule itself, where you fill in all of the following fields: dict_keys(['fig Report the name of the model with the highest average energy.', 'fig Report the name of the model with the lowest average wait time.']). You should install all of the requirements found in the Readme file and then run the commands necessary to answer the questions.
