Task: codeocean_hard

Your goal is to test the computational reproducibility of the repository cloned to your current directory, which is code from a scientific paper. Specifically, you need to Run '01_code.R' using Rscript. Save your report to a file named report.json in the environment directory you started in that contains the capsule itself, where you fill in all of the following fields: dict_keys(['fig Report a Python list of three elements with the three Type-1 error rates (alpha values) measured in the estimate-comparison test and the sign-comparison test. Sort the list in descending order.']). You should install all of the requirements found in the Readme file and then run the commands necessary to answer the questions.
