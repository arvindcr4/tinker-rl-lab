Task: codeocean_hard

Your goal is to test the computational reproducibility of the repository cloned to your current directory, which is code from a scientific paper. Specifically, you need to Make the following subfolders in the ../results directory: tables, figures, for_publication/tables, for_publication/figures. Run all the .R scripts in the ../code folder using Rscript with 'source' and set echo to 'TRUE'.. Save your report to a file named report.json in the environment directory you started in that contains the capsule itself, where you fill in all of the following fields: dict_keys(['fig From figure 3 from the figures for publication, report the name of the party ID with the lowest share of political news from portals.', 'fig Report the y-axis label of the figure showing the distribution of avg. alignment by party.']). You should install all of the requirements found in the Readme file and then run the commands necessary to answer the questions.
