Task: codeocean_hard

Your goal is to test the computational reproducibility of the repository cloned to your current directory, which is code from a scientific paper. Specifically, you need to Run 'epidemic.py'.. Save your report to a file named report.json in the environment directory you started in that contains the capsule itself, where you fill in all of the following fields: dict_keys(['fig For the third subplot in the visualization of the experiments, report the color of the line with the greatest number of nodes at epoch 15.', 'fig Report the name of the first subplot in the visualization of the experiments.']). You should install all of the requirements found in the Readme file and then run the commands necessary to answer the questions.
