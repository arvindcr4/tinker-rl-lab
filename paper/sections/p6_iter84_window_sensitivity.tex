\subsection{Window-sensitivity registry schema backfill (iter 84 SYNTH)}
\label{sec:p6-window-sensitivity-backfill}

The iter-82 row 97 audit documented that the same-stack variant deltas
are panel-sensitive: the registry records measurements against
\verb|panel=n2_same_stack_last10|, but a fresh window-by-window
re-measurement (paired-step bootstrap, $B=2000$, seed 20260705) shows
that the same-sign significance holds across panels for only 6 of 12
cells. The iter-82 audit recommended (and deferred) a schema bump to
make this property machine-readable. This iter lands the bump.

\subsubsection{Schema extension}
Two new optional fields on \verb|measured_delta|:
\begin{itemize}
\item \texttt{window\_sensitivity} (string enum):
      \texttt{STABLE} / \texttt{STABLE-DIRECTION-MAG-SHIFT} /
      \texttt{FRAGILE-SIGN-FLIP}.  Default =
      \texttt{STABLE-DIRECTION-MAG-SHIFT}.
\item \texttt{robust\_panel} (string enum):
      \texttt{full40} / \texttt{last20} / \texttt{last10} / \texttt{last5} /
      \texttt{none}. The largest-window panel at which the same-sign
      significance holds; \texttt{none} if no panel is significant.
\end{itemize}
Both fields are \emph{additive, optional, nullable}.
\texttt{additionalProperties:false} is preserved. \textbf{35/35 registry
entries pass jsonschema validation post-bump.}

\subsubsection{Classification rule}
Per (method, metric) cell:
\begin{itemize}
\item \textbf{\texttt{FRAGILE-SIGN-FLIP}} if $\sign(\delta_{\mathrm{full40}})
      \neq \sign(\delta_{\mathrm{last5}})$ \emph{AND} both $|\delta| > 0.005$
      (the noise floor the iter-82 data requires).
\item \textbf{\texttt{STABLE}} if all three panels (full40, last10, last5)
      are significant AND the same-sign relative magnitude change
      $|\delta_{\mathrm{full40}} - \delta_{\mathrm{last5}}| /
      |\delta_{\mathrm{full40}}| < 0.30$.
\item \textbf{\texttt{STABLE-DIRECTION-MAG-SHIFT}} (default) otherwise.
\end{itemize}

The \verb|robust_panel| resolves as: aero.zvf $\to$ none (no same-sign panel sig);
aero.reward\_mean $\to$ last10; gift.zvf $\to$ full40;
gift.reward\_mean $\to$ full40; gift.mean\_len $\to$ last5;
areal.reward\_mean $\to$ last10. \textbf{5/6 cells resolve to last10,
full40, or last5} --- consistent with the iter-82 row 97 finding that the
registry's \texttt{panel=n2\_same\_stack\_last10} choice was a
\emph{defensible} default, not a cherry-pick.
