# demo_recording/ — INDEX

**Purpose:** Presentation deliverables for the TinkerRL-bench demo (HF Space): screenshots, screencasts, and ffmpeg concat scripts used to build the demo videos for the talk.

**Key files:**
- `README.md` — live Space URL, how to play the demo in the deck, narration script, redeploy/wake commands.
- `demo.mp4` / `demo_v2.mp4` / `demo_v3.mp4` / `demo_browser.mp4` — pre-recorded demo cuts (v3 is latest; browser = screencapture version).
- `concat.txt` / `concat_v2.txt` / `concat_v3.txt` — ffmpeg image-concat slideshows (file + per-slide duration) that build the MP4s.
- PNGs — embed-ready screenshots. Two naming families: numbered talk-order (`01_tool_use.png`, `01b_metrics.png`, `02_zvf.png`, `03_artifacts.png`, `04_headline.png`, `04–10_models_*.png`) and v3 series (`v3_01.png`…`v3_10.png`); `space_main.png` = Space landing.

**Subfolders:**
- `browser_video/` — raw captured browser `.webm` (see its INDEX.md).

**Find it fast:**
- to play the demo in the deck → `demo.mp4` (+ `README.md`)
- to rebuild a video → `concat_v3.txt`
