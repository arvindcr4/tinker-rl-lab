# v0.9-pre-submission cover email drafts

Two variants, placeholders to fill in:

- **`cover_email_venue_general.md`** — neutral, works for any venue.
- **`cover_email_eai.md`** — EAI Endorsed Transactions-tuned.
- **`cover_email_neurips.md`** — NeurIPS/ICML-tuned.

## Placeholders to fill in

| Placeholder | Where to get it |
|---|---|
| `[Your Name]` | yours |
| `[your-academic-email]` | yours |
| `[Affiliation]` | yours |
| `[ORCID]` | https://orcid.org |
| `[Contact]` | phone / mailing if required |
| `[Editor / Track Chair]` | venue's editorial office |
| `[Track Name]` | venue's submission system |
| `[Editor-in-Chief of EAI Endorsed Transactions]` | https://eai.org |
| `[ac-XXX@neurips.cc]` | NeurIPS OpenReview |
| `[Reviewer 1/2/3]` | your suggestion list |
| `[Conflicts of interest]` | your actual disclosures |

## Differences between the three variants

| | general | eai | neurips |
|---|---|---|---|
| Subject line | generic | EAI Editorial Office | AC of track X |
| Scope language | "audit / diagnostic" | "engineering diagnostic for open-access dissemination" | "methodological / NeurIPS-style concerns" |
| Novelty call-out | 3 bullets | 4 numbered bullets | 3 numbered bullets |
| Reproducibility | tag + W&B | tag + W&B + audits | tag + W&B + audits |
| Reviewer suggestions | generic | generic | specific to track |

## What to do before sending

1. Confirm venue + track (EAI vs. NeurIPS vs. something else)
2. Fill in placeholders
3. Get co-author sign-off
4. Attach: anonymised PDF (or main PDF if not blind), supplementary,
   data/code statement, conflict-of-interest form if required
5. Check that the attached PDF matches the tag's `paper/main.pdf`
   (or `reports/final/grpo_agentic_llm_paper_anonymous.pdf` for blind)
6. Verify reviewer suggestions have email + affiliation + no conflict
