\section{Benchmark Dataset and Reproduction Harness Architecture}
\label{sec:appendix:architecture}

This section provides structural architectural diagrams for the eight core
pipelines that govern data ingestion, quality filtering, licensing,
evaluation, contamination auditing, and reproduction in \ours{}.

\subsection{Evidence Tiering and Open Distribution}
Figure~\ref{fig:r04_dataset_tiering} outlines the classification pipeline
that partitions raw experimental traces into Tier~A (analytic / multi-seed
inferential), Tier~B (single-seed descriptive case studies), and Tier~C
(uncompleted or diagnostic-only cells).
Figure~\ref{fig:r04_license_pipeline} documents the automated license checker
verifying open-access redistribution terms across all bundled datasets.

\subsection{Evaluation, Leakage Auditing, and Version Control}
Figure~\ref{fig:r04_eval_harness} shows the evaluation pipeline that executes
held-out assessment suites across checkpoints.
Figure~\ref{fig:r04_leakage_audit} outlines the automated contamination audit
that computes 8-gram and 13-gram overlaps between training prompts and held-out
test splits to prevent data leakage.
Figure~\ref{fig:r04_version_control} illustrates dataset version management,
tagging every release commit with immutable cryptographic digests.
