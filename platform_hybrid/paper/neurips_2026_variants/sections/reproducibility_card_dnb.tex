\subsection{Reproduction entry points (make targets not yet released)}
\label{sec:repro-onecmd}

The repository's top-level \texttt{Makefile} does not yet provide the
one-command targets planned for this artifact (\texttt{smoke-test},
\texttt{reproduce-main}, \texttt{reproduce-appendix}); no clean-environment
end-to-end run is certified by this manuscript. The available entry points
are the per-experiment commands in \texttt{REPRODUCE.md} and the per-run JSON
files under \texttt{experiments/tinker-runs/results/}, from which every row of
Table~\ref{tab:main_results} can be recomputed (peak and last-10 mean of
\texttt{reward\_trace}). Logged wall-clock is short for the open-stack
cells: the five TRL Qwen2.5-0.5B seeds record 135--183\,s each on an L4, and
the Tianshou PPO floor runs log under 3\,s; we report no estimate for a
full re-run.

\paragraph{Closed-backend cells.}
Tinker case-study cells cannot be re-run without Tinker credentials; for them
we ship the JSON step logs and the API-call scripts, and replication is subject
to the JWT-expiry failure modes documented in the manifest
(Appendix~\ref{sec:run-manifest}).

\paragraph{Hash manifest.}
A file-level SHA-256 inventory (\texttt{REPRODUCIBILITY\_HASHES.json}) is
planned but not released. Equal hashes would test byte equality of
deterministic outputs only; stochastic comparison requires named metrics,
independent units, effect intervals and prespecified tolerances.

\paragraph{Submission-time status.}
Table~\ref{tab:artifact-card} checkmarks must not be read as successful
target execution or downloadable adapter proof. The separate five-seed
held-out Qwen3-8B comparison is outside this release's inferential evidence.
