\subsection{Reproduction entry points}
\label{sec:repro-onecmd}

At submission the repository has \emph{no} one-command reproduction target:
the top-level \texttt{Makefile} provides only lint, test, packaging and
submission checks, and no \texttt{make reproduce-*} target exists. Earlier
drafts described \texttt{make smoke-test}, \texttt{make reproduce-main} and
\texttt{make reproduce-appendix} with wall-clock estimates; those targets were
never implemented and the estimates were not measured, so both are withdrawn.
The available entry points are per-experiment scripts:
\begin{itemize}\setlength\itemsep{1pt}
  \item Offline checks: the unit tests and replay commands listed in
        \texttt{REPRODUCE.md} (no GPU, no credentials).
  \item Open-stack Modal cells: the Modal drivers under
        \texttt{platform\_hybrid/\allowbreak{}experiments/\allowbreak{}modal/\allowbreak{}} (e.g.\
        \texttt{modal\_ppo\_campaign.py}, \texttt{modal\_grpo\_trl.py},
        \texttt{modal\_groupsize\_zvf\_sweep.py}); these require a Modal
        account and GPU spend.
  \item Tinker cells: the API-call scripts under
        \texttt{platform\_hybrid/\allowbreak{}experiments/\allowbreak{}tinker-runs/\allowbreak{}}; replication
        requires Tinker credentials and is exposed to the JWT-expiry failure
        modes documented in the manifest (Appendix~\ref{sec:run-manifest}).
\end{itemize}
No clean-environment end-to-end run of these scripts is certified by this
manuscript, and no reference hash manifest is released.
Table~\ref{tab:artifact-card} checkmarks are historical availability reports,
not proof of successful re-execution or of downloadable adapters.
