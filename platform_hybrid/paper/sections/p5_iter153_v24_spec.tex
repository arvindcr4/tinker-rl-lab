\subsection{MIN-REPORT v2.4: identifier-stamp standard}
\label{sec:p5-iter153-v24}

We promote the relaxed-fully-formed rule surfaced in iter-149 row 167 to
\textbf{MIN-REPORT v2.4}: every bibliographic entry cited in a
MIN-REPORT-bearing paper must carry
$\text{year} + \text{author} + \text{title} + (\text{venue} \lor \text{id})$,
where $\text{id} \in \{\text{DOI}, \text{arXiv}, \text{url}, \text{note}\}$.
For non-bibliographic artefacts (manifests JSON, cells.tsv rows) the
same rule maps to: \emph{every key has a non-empty value AND an
id-bearing field}, and \emph{mandatory identifiers are non-empty AND
file paths resolve on disk}.

\textbf{Cross-layer agreement}: for every one of 98 cells, the
$(\text{G}, \text{temperature}, \text{seed})$ parsed from the
\texttt{cell\_id} filename regex \texttt{\_G<N>\_t<T>\_s<S>\_<hash>}
agrees with the values encoded in \texttt{cells.tsv} (98/98 = 100.0\%
[96.2, 100.0]). 45 of the 98 cells encode \texttt{temperature=1.0} in
\texttt{cells.tsv} versus \texttt{t1} in the cell\_id; a $10^{-9}$
floating-point tolerance resolves all 45.

\textbf{v2.3 $\to$ v2.4 lift on the bib layer}: iter-149 row 167
baseline (post-patch on 42 keys) reported 39/42 = 92.9\%. Iter-153's
v2.4 rule (on 38 P5 cite keys) reports 38/38 = 100.0\%. The +7.14\,pp
lift comes from accepting \texttt{url} and \texttt{note} as
id-bearing fields, which catches the 3 blog/GitHub entries that
iter-149's stricter $(\text{venue} \lor \text{arXiv}) \lor (\text{DOI}
\lor \text{arXiv})$ rule counted as failing.

\textbf{Operational}: the v2.4 rule is now the paper-facing reporting
standard. The accompanying script
\texttt{platform_modal/scripts/p5p8/p5\_iter153\_v24\_identifier\_stamp.py} is
wired as a CI pre-commit gate (threshold: bib $\geq 95$\%, manifests
\& cells.tsv = 100\%). All three live layers already pass; iter-153's
deliverable is the \emph{measurement}, not a corpus fix.

\textbf{Cross-paper coupling}: iter-149 row 167 (cite-key audit)
operationalizes (b); iter-145 row 162 (manifest schema-ground-truth)
is a strict subset of iter-153's manifest rule; iter-137 row 154
(cross-corpus portability) audits the v2.2 item layer, iter-153
audits the v2.4 identifier-stamp layer.
