\section{Reading Guide: Evidence Base and Its Provenance}
\label{sec:p5-results}
Because this is a position paper, we separate what we argue from what we
measured, and we label the provenance of every number. Three evidence strata
appear below. \textbf{Stratum A} is the \ours{} benchmark described in
\secref{sec:benchmark} and \secref{sec:setup}: controlled runs under the shared
seed policy and statistical tiers, with artifacts in the released repository
(per-library ZVF aggregations, matched-configuration framework dumps, and the
same-stack PPO-vs-GRPO isolation runs). \textbf{Stratum B} is a set of internal
program records from our June 2026 ZVF audit program (a 368-run Weights \&
Biases audit within a 790-run corpus, a 12-cell Tinker head-to-head, an
under-specified same-label comparison, and a single-file open-trainer reimplementation audit); we
report these as internal experimental records, and the worked example in
Appendix~\ref{app:p5-worked} shows the manifests that make such records
comparable at all. \textbf{Stratum C} is toy-scale theory validation (a 0.5B
model on synthetic arithmetic with an open backward pass); Stratum-C results are
directional only and are flagged as such wherever used.

The argument then proceeds in four steps. \secref{sec:p5-evidence} presents the
exhibits: the stack moves outcomes by more than the label does, and the label
does not pin down the experiment. \secref{sec:p5-stack} converts the exhibits
into a standard---the eight-item minimum reportable stack---where each item is
included if and only if we can point to a documented lever through which that
item moved or flipped a result. \secref{sec:p5-threat} generalizes from
exhibits to a threat model: the confound vectors an adversarial (or merely
careless) comparison can ride, graded by flip risk. \secref{sec:p5-toolchain}
shows the standard is cheap to enforce mechanically, which is what
distinguishes a checklist that changes practice from one that decorates
appendices \citep{pineau2020improving}.
