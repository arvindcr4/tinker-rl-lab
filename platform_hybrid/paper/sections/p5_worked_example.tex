\section{Worked Example: Two ``DAPO'' Manifests and Their Verdict}
\label{app:p5-worked}
This appendix instantiates the standard end-to-end on the two arms of
Exhibit 2 (\secref{sec:p5-exhibit-label}): the same algorithm label, run on a
closed training stack and on an open single-file trainer. The manifests are
hand-written from the run records and runner code cited in each
\texttt{source} field; values the records do not contain are written
\texttt{"not-recorded"} rather than guessed. Field values marked
\texttt{"provider-internal"} illustrate the disclosure convention for closed
stacks (\secref{sec:p5-conclusion}): a closed value is acceptable; an absent
field is not.

\subsection{The Stackdiff Verdict}
\label{app:p5-verdict}
Running the differ on the two hand-written manifests above, with the grade
classes of \secref{sec:p5-grades}:
\begin{lstlisting}[basicstyle=\ttfamily\footnotesize, frame=single,
                   breaklines=true, columns=fullflexible]
$ grpo-stackdiff manifest_a.json manifest_b.json

FIELD DIFF
  R5 base_checkpoint                Qwen3.5-4B       != Qwen2.5-0.5B-Instruct
  R5 task / reward                  gsm8k            != synthetic addition
  R4 loss_form.ratio_level          none             != sequence
  R4 loss_form.clip                 adv [-2,3]       != ratio [0.20,0.28]
  R4 loss_form.dynamic_sampling     false            != true
  R3 decoding                       T=0.8, 512 tok   != T=1.0, 40 tok
  R3 group_size.G                   8                != 4
  R2 sampler_backend.trainer        tinker (closed)  != open single-file
  R2 sampler_backend.precision      provider-internal!= bf16
  -- zvf_gu_trace.mean_zvf          0.578            != 0.00   [consequence]
UNKNOWN: checkpoint revisions (R5), held-out disjointness (R5)

FLIP-RISK GRADE: R5; UNDERSPECIFIED (unknown R5 fields)
  Label collision: same label_claimed "DAPO" with differing R4 fields.

CI VERDICT: NOT-COMPARABLE
  Do not report these runs as "DAPO vs DAPO". Qualified labels required:
    manifest_a -> DAPO(advantage-clip surrogate, no-dynamic-sampling)
    manifest_b -> DAPO(ratio-clip, dynamic-sampling)
  A bridging run on a common stack is required before any algorithmic claim.
\end{lstlisting}
The diff makes Exhibit 2 mechanical: the telemetry inversion (mean ZVF $0.578$
vs.\ $0.00$) is listed not as a difference to adjudicate but as a
\emph{consequence} of the item-1 divergence, and the verdict line is exactly
what a leaderboard CI job would gate on. Note also what the diff does
\emph{not} say: it does not claim either run is wrong, or that the closed
stack is inferior---only that the pair cannot support a label-level
conclusion. That restraint is the entire content of the standard.
