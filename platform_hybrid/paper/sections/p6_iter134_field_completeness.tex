\subsection{Per-row measured-field completeness audit (iter 134)}
\label{sec:p6-iter134-field-completeness}

Iter-126 classified each of the 15 variant-delta entries by the \emph{evidence
tier} its measured rows attain. Iter-134 audits the same measured rows at a
finer granularity: for every one of 38 measured rows, classify each of 11
base fields plus 9 extension fields as PRESENT / NULL; verify CI consistency
($\mathit{ci\_low} \leq \mathit{delta} \leq \mathit{ci\_high}$); verify
provenance (the \texttt{source} path resolves to a real file on disk); and
classify each row's \texttt{ci\_method} as either a proper object or a
shape-violating string.

\subsubsection{CI consistency and provenance integrity}
\label{sec:p6-iter134-integrity}

Two integrity checks per measured row: (i) the 95\% CI brackets the point
estimate ($\mathit{ci\_low} \leq \mathit{delta} \leq \mathit{ci\_high}$);
(ii) the \texttt{source} path resolves to a real file on disk.
\textbf{H2 (PASS)} --- 38/38 measured rows pass both checks. Of 38 rows,
\textbf{21 (55.3\%) are significant} ($\mathit{significant} = \mathit{true}$);
the remaining 17 are null-effects or directional-but-noisy.

from a string to a canonical object. Iter-134 finds \textbf{8 measured rows
where \texttt{ci\_method} is a string} (\texttt{"bootstrap\_paired\_5seed"})

\texttt{expected\_effects} AND \texttt{measured} --- these are the
deepest evidence gaps in the registry today.

unchanged); 8 use \texttt{seed=None} because \texttt{normal\_approx\_welch}
legitimately has no bootstrap seed (Welch's t).
