\subsection{N2 panel recompute and prose-vs-measured direction audit (iter 150)}
\label{sec:p6-iter150-recompute-prose}

Iter-106 enumerated every measured row in the registry and bound it to a
\texttt{panel}; iter-126 tier-classified the depth of that evidence per
delta; iter-134 closed the field-completeness leg; iter-138 added the
missing methods; iter-142 connected tier to per-cell
\texttt{claim\_validation} verdicts and named the $\eta^2(\text{method})
= 0.0005$ under-identification paradox. Iter-150 closes two open legs:
(1) \emph{freshness} --- does each stored measured row still reproduce
from the raw \texttt{n2\_metrics.tsv} after 30+ iteration cycles; (2)
\emph{prose direction alignment} --- does the prose claim attached to
each delta's \texttt{deltas[].change} agree with the measured sign on
N2?

\paragraph{Freshness recompute.}
For each of the 12 measured[] rows whose panel contains \texttt{n2}, we
recompute the paired step difference (variant minus \texttt{grpo}) on
the panel's window and compare to the stored \texttt{delta} and CI.
The recompute uses a deterministic normal-approx CI; the registry's
stored CI is bootstrap-paired, so the widths differ slightly, but the
point estimate must match and the SIGN must match (drift between
normal-approx and bootstrap is bounded by $\sqrt{n}$).

\paragraph{Prose-vs-measured direction.}
For each \texttt{delta\_*.json}, we scan the prose
\texttt{deltas[].change} text for keywords that imply a measurable
direction on a specific metric (zvf, reward\_mean, mean\_len, loss).
When a measured row exists for that metric on
\texttt{n2\_same\_stack\_last10}, we test whether the measured sign
agrees with the prose-implied direction. Of 21 prose components
surveyed across 17 entries:

\begin{itemize}
\item \textbf{7} have both prose and a measured row on the panel.
\item \textbf{11} have prose but no measured row for the implied metric
(\texttt{PROSE\_HAS\_NO\_MEASURE}).
\item \textbf{3} are prose-only with direction orthogonal to the panel
metrics (\texttt{ORTHOGONAL}).
\end{itemize}

\paragraph{Interpretation.}
\textbf{AERO} (\texttt{le2025rlzvp}, arXiv:2509.21880) claims its
off-policy reference rollouts ``inflate the effective group size
without resampling.'' On the N2 same-stack panel this should \emph{raise}
ZVF by exposing more zero-variance prompts. Measured $\Delta \text{ZVF}
= -0.025$ (NS, but trending the opposite way). The registry already
flagged \texttt{window\_sensitivity: STABLE-DIRECTION-MAG-SHIFT} on this
row, so the direction is robust across windows but the prose sign
contradicts the measurement.

\textbf{GIFT} claims its gamma-style per-prompt likelihood prior should
``shift zvf distribution'' (down, implicitly, because subtracting a
prior reduces per-prompt variance). Measured $\Delta \text{ZVF} = +0.125$
(SIG, $p < 0.001$ by paired bootstrap, robust on full-40 and last-10).
The measurement is robust; the prose direction is wrong.

Both disagreements are stored in
\texttt{experiments/results/p5p8/p6\_iter150\_summary.json} under
\texttt{disagree\_entries} and constitute a non-trivial validation
finding: two of the four GRPO-family variants whose prose claims
predict a measurable ZVF direction actually shift ZVF in the opposite
direction on the N2 same-stack panel. This is the registry performing
its job --- surfacing where the prose mechanism description and the
measured same-stack behavior diverge --- and it generalises the
iter-126 tier-B/iter-142 UNCLAIMED audit by attaching a sign-concordance
test rather than a coverage test.

\paragraph{Open gap: PROSE\_HAS\_NO\_MEASURE.}
11 prose components (dapo/gspo/mcgrpo/scafgrpo/ppo/reinforce/liteppo)
imply a measurable effect on a metric for which the registry has no
measured row on any panel. This is a different kind of gap from the two
above: the prose claim is \emph{unfalsified}, not \emph{contradicted}.
Recommended cure for iter 151 is to add a \texttt{provenance\_only}
measured row for each of these variants, recording either the published
same-stack number or the citation in which the claimed effect was first
quantified.
