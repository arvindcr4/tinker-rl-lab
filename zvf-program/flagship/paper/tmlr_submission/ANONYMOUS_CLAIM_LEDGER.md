# Anonymous claim ledger

The manuscript uses four labels: sourced background, proved, artifact-checked,
and not established. The verifier checks executable identities and receipt
invariants; the written proofs remain the source for the propositions.

| ID | Claim | Status | Boundary |
|---|---|---|---|
| C1 | A conditionally independent binary group is homogeneous with probability `p^G + (1-p)^G`. | Sourced background | Not novel; does not cover correlated or nonbinary rewards. |
| C2 | The first mixed group has the stated geometric waiting time under stationary, independent groups. | Proved | Not an adaptive-policy theorem. |
| C3 | Fixed-size complete groups have boundary cost `1/epsilon + O_G(1)`, and every complete group size obeys the stated `1/epsilon` lower bound. | Proved | Counts rollouts, not gradient quality or end-to-end learning. |
| C4 | In the stated two-state, two-action prepaid-batch problem, the same terminal history can reverse the optimal action and yields positive minimax regret. | Proved | Does not cover arbitrary sequential controllers. |
| C5 | The frozen S1 projections contain 14 intended cases per stack and a shared 36-case controller matrix, with every intended case passing its declared reference. | Artifact-checked | Small CPU fixtures; not end-to-end framework equivalence. |
| C6 | Native traces differ from the declared reference on four tested TRL cases and one tested verl case. | Artifact-checked | A difference label is not a framework bug or quality ranking. |
| C7 | The r4-2 state partitions 31 jobs into 10 accepted, 14 contract-infeasible, 2 infrastructure-failed, 1 validation-failed, and 4 quota-pending jobs. | Artifact-checked | An exact disposition, not a completed experiment. |
| C8 | The sole completed intended-full balanced cell meets the joint registered predicate on 69/100 steps, below the required 95/100. | Registered gate failed | High cosine alone is descriptive and cannot replace the frozen joint predicate. |

The anonymous receipt files retain all values needed for C5--C9. Their
`original_*_sha256` fields bind each projection to the unredacted audit object,
which is withheld only for double-blind review.
