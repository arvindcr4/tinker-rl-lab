Both arms appear in both pipelines and all other tasks are explicitly excluded. | The verifier pins both training/evaluation corpus revisions, requires the exact 2-by-2 task-arm matrix, and rejects a missing, duplicated, or drifted cell. | All four cells and any variance-amendment seeds must be executed. |
| Several comparisons used one seed. | Sixteen paired seeds per cell are derived from the worst E1 capability variance, then protected by a blinded dual-endpoint reassessment that may only increase the count. | Unique preregistered seeds, exact power arithmetic, joint cost/capability reassessment, and a fail-closed 24-seed cap are enforced. | The first eight pairs per cell must run before final sample size is frozen. |
| Optimization steps or checkpoints were treated like replications. | The independent unit is the training seed within a frozen task-model-stack cell. | The verifier fixes the independent-unit text and result schema key. | Analysis code must preserve seed pairing and treat prompt/item bootstrap as secondary. |
| Online reward and proxy diagnostics were conflated with capability. | Cost, online telemetry, verifier behavior, and fixed held-out exact match occupy separate fields and claims. | The claim ledger binds capability only to paired held-out columns; mechanism telemetry cannot upgrade primary claims. | Independent parser audit and all fixed held-out traces must be completed. |
| Heterogeneous algorithms and stacks prevented identification. | One model, one stack, one canonical objective, and one sampling-policy intervention are used. | Two exact arm IDs, frozen treatment fields, executable hashes, sampler conformance tests, and preflight receipt validation are required. | The remote four-cell preflight and confirmatory matrix still need execution. |
| Post-submission evidence was difficult to assess. | E1 supplies only a conservative planning variance; its arm verdicts are quarantined. | The prior-evidence boundary rejects any promotion of the stale aggregate. | New results must be generated under the new protocol and cannot reuse E1 cells. |

Passing the design verifier means the protocol closes the known review loopholes and that GPU execution is scoped by a bound authorization receipt. It is not experimental evidence, a completed external use case, publication authority, or submission readiness.
